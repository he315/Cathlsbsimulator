# S13: real-angiogram reading drills and content integrity

Stream S13 of the realism plan. It fixes the CADICA scoring bug, makes every real-image drill
resistant to guessing, adds lesion localisation, stenosis estimation and next-view planning with
confidence calibration, removes the answer-length giveaway from the Academy quizzes, and gives the
cases real consequence branches. Facts and parameters: `docs/realism/facts/S13.md`.

## The drills

All sets except next-view planning are stratified: the same number of items from every reference
class (`stratifiedSample`; occlusion and collaterals use matched pairs, below). Next-view planning is
not stratified because its reference is one operator's practice; its report says so and shows the
raw accuracy of the best constant answer on that set.
Every answer carries a confidence slider. A finished set shows balanced accuracy against chance,
Cohen's kappa with an approximate 95% CI, raw accuracy, Brier score and a confidence-calibration
table; ordinal drills add linear weighted kappa and signed over- or under-calling bias. Each answer is
scheduled with the quiz SM-2 rule (`review()` from `src/simulation/srs.ts`) under its own key
`cathmaster:v1:angio-srs` (`angio:<drill>:<runId>` items), not in `profile.quizMemory`, so the dashboard's
quiz due count and the Review page agree. Records an earlier S13 build wrote into `quizMemory` are moved
across once (`migrateAngioMemory`, run when the drills mount). Each answer also goes to a local results
log used by the Progress tab's learning curves, whose dashed reference line is each drill's chance level
(1 / number of reference classes answered). The set score recorded with `recordSim("angio-<drill>")`
is the balanced accuracy, so it cannot be raised by guessing.

### Occlusion and collaterals: domain confound removed

Every occlusion- or collateral-tagged run is in the CoronaryDominance main set (`dominance-main`); the
domain-shift subset (`dominance`) has no positive tags at all. The earlier build took negatives from
studies with no category, which are exactly the domain-shift subset (occlusion 216 positives all main,
97 negatives all domain-shift; collaterals 691 against 329), so the subset decided the label. Within the
main set the artefact tag is also confounded: 70 of 72 clean RCA runs are artefact-tagged against 11 of
216 occluded ones. The drills now:

- use main-set runs only, with an explicit `false` tag, from studies with no run tagged for that finding,
  leaving out runs flagged uncertain;
- pair each positive with a negative from the same nuisance stratum (subset and artefact tag,
  `nuisanceStratum`, `matchedPairs`) and draw 6 pairs per set.

Measured pools: occlusion 216 positives, 72 negatives, 13 matched pairs (11 artefact, 2 clean images);
collaterals 691 positives, 214 negatives, 41 pairs (31 and 10). In every set, the artefact tag and the
subset are independent of the label (tested over 20 seeds). The cost is a small occlusion pool, so runs
repeat between sets; the drill blurb says so.

### Raw accuracy and the constant answerer

Balanced accuracy is 1/K for any constant answer by construction, so the tests now also check what the
sets themselves do: every set has equal counts per reference class, and a constant answerer's raw
accuracy equals chance in every stratified drill (0.5 in the yes/no drills, 0.25 in grade and estimate,
0.5 for "no lesion" in locate) and in the strict projection set. With borderline acceptance, one view
name can be right on neighbouring classes, so the best constant answer exceeds 1/K (all 20 tested sets);
the view report shows that baseline and points to the strict option. Plan sets are labelled
unstratified with the same baseline.

### Drill parameters

A `drill` block may carry parameters, now applied rather than dropped. `DRILL_PARAM_RULES` in
`schema.ts` lists them: `artery` (`LCA` or `RCA`) for view, grade, locate and estimate, and `borderline`
(`accept` or `exclude`) for view. The validator rejects any other key, value or drill, so a parameter
in content always takes effect. The section applies them to the drill they came with, shows "From the
lesson: ..." with an "All runs" button that clears them.

The patient-cases tab now uses CADICA's own patient-level classes (<20%, 20-50%, >70%) with label
normalisation (42 of 42 scorable, previously 6) and hides the expert boxes until the report is shown.

## Verification

- `npx vitest run src/content`: 53 passed (52 in content.test.ts, 1 published-case check), 1 skipped (the per-author track check, skipped by design).
- `npx tsc --noEmit -p .`: zero errors in the whole project at the time of writing.
- Constant answerers: in every drill, over 20 random sets each, balanced accuracy equals chance
  (0.5 in binary drills; 1/K otherwise, or 0 for a label that never occurs) and kappa is 0 within 1e-6.
  Every stratified set has equal counts per reference class, and raw accuracy of a constant answer is
  exactly chance in all stratified drills except the view drill with borderline acceptance, where the
  report shows the higher constant-answer baseline.
  An expert reader scores accuracy 1, kappa 1, Brier 0.
- Library base rates that unstratified sets would reward: right dominant 77.3%, LCA 71.8%,
  borderline projections 34.7%.
- Academy: before, 352 of 542 items had the correct option uniquely longest and 65 of 68 modules would
  fail the rule; after, 109 items are flagged, the worst module is at 25%, "always pick the longest"
  scores 22.7% against chance 21.3%, and "always pick the shortest" 13.8%. No explanation refers to an
  option by position, so QuizRunner shuffles every item.
- Cases: 0 of 257 steps branched before; 130 of 373 (34.9%) now branch, every step is reachable and no
  path loops. Branches in published cases are marked "Teaching branch, not part of the published report".
- Browser checks were not allowed for this stream. The drill cards and set reports for all nine drills
  are rendered server-side in the test suite to catch render-time errors.

## Performance

No change to the X-ray renderer. The cine player draws one 2D `drawImage` per acquired frame (10-15
frames/s) plus a few strokes for boxes and marks. Building a set takes about 7 ms (view drill, 1,625
runs) and happens on a click. Results are appended to localStorage once per answer.

## Known limitations

- The ARCADE segment-naming drill was not built: the plan gates it on an approved download and
  licence confirmation, neither of which has happened.
- Plan acceptance asked for the inter-observer calibration drill on CoronaryDominance studies; that
  dataset has no stenosis labels, so the calibration (estimate) drill runs on CADICA lesions and the
  next-view drill runs on CoronaryDominance.
- Next-view planning compares with one operator's sequence, and acquisition order is inferred from
  the run-id suffix. Its sets are not stratified (labelled in the report).
- The occlusion drill has only 13 same-domain matched pairs, so a 6-pair set repeats runs across sets.
  Most pairs are artefact-tagged images, because the main set has almost no clean, non-occluded RCA runs.
- Locate accepts a hit on any boxed lesion; it does not test whether the learner picked the most severe
  one. That is what the grade drill tests.
- Kappa confidence intervals use the large-sample approximation and are wide for 10-18 item sets; the
  Progress tab pools all answers per drill.
- Item analytics are computed per attempt in a single browser; point-biserial needs at least three
  attempts per item to be defined.
- The stability score is a teaching device; its values are model parameters.
- Consequence steps in published cases are hypothetical branches, labelled as such.
