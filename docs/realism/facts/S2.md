# S2 facts: detector, processing chain and field

Every constant in `src/render/xray/{XrayRenderer,detector,pyramid,systemProfiles,renderer.perf}.ts`
falls into one of three classes below. No vendor specification value is used anywhere (in particular,
the "MTF(1 lp/mm) = 59 %" figure from the plan was not used, because its source URL is not recorded;
see critique items 29 and 34). Profiles are named A, B and C, not after products.

## 3. Model parameters (tuning constants, named as such in code comments)

Tuned by capturing frames from the renderer and running the scripts above on them (method in
`docs/realism/wave1/S2.md`). None is a physical measurement.

- Profiles A/B/C: `mtfSigma512`, `quantumEfficiency` (A 2.2, B 2.0, C 0.5), `electronicSigma`
  (2 quanta), `floorGrey` (A 4.6, B 2.6, C 7.9), `floorRefCounts` (1500 = the scene builder's cine
  AEC target, so the floor scales as sqrt(1500/counts)), `floorDarkSlope` (A 0.13; fitted with
  `quantumEfficiency` and `floorGrey` on six view families so the dark/bright ratio is 1.13-1.24
  in each; method and numbers in `docs/realism/wave1/S2.md`), `floorG0` 0.55, `bandGains`,
  `residualGain` (A 0.42; 0.36 and 0.30 tried, see S2.md section 5), `coring`, LUT shape (logistic
  slope 3.2 / 3.0), `toneRatioMax` 2.5, `lagFrames` 3, `fluoroRecursion` 0.4, `motionC` 2.5.
- Field fits: A amp 0.07, lambda 3.0 px, power 1; B amp 0.44, lambda 10.2 px, power 1.35, corner
  radius 24 px; C amp 0.11, lambda 1.02 px. Fitted by hand to the band ratios in section 2
  (for B: -ln(F/A) against d gives a log-log slope of 1.3-1.45, hence power 1.35).
- Detector: `BLADE_TRANSMISSION` 0.03, `DEFAULT_WEDGE_TRANSMISSION` 0.4, `DEFAULT_PENUMBRA_PX` 6
  (plan target 4-8 px), `GRID_OUT_SPR_FACTOR` 2.5, `SCATTER_KERNELS` (mip 5.0/6.5/7.5, weights
  0.3/0.4/0.3).
- Renderer: `RUN_GAP_MS` 400 and `RUN_GAP_FACTOR` 3 (a new run starts after a gap longer than
  max(400 ms, 3 x the median recent frame interval)), L clamp [-6, 7], meter subsample about
  128 x 128 points, `REFERENCE_RES` 768 (the render size the profiles were fitted at; noise per
  pixel scales as res / 768 in SD so the noise per unit area is constant, and band gains are read
  at the physical scale).
- Resolution policy: `maxRes` 1024, `fallbackRes` 768 and `budgetMs` 25 come from the plan's
  frame-budget task; `probeEvery` 90 frames and "two consecutive probes over budget" are model
  parameters. The Lanczos-3 kernel (a = 3) is the standard definition sinc(x) sinc(x / 3), no
  numeric fact beyond it.
- Perf: `recommendResolution` 25 ms threshold (from the plan's frame-budget task); timer-query
  plausibility limit 1.5 x the measured frame wall time; wall time sampled every 8th frame in
  timer-query mode.
