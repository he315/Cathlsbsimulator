# pci-assessment-policy-qca: model parameters

Assessment-mode policy, trainee QCA and removal of revealed ground truth in the PCI lab: the PCI branch of the lab policy (`src/ui/lab/visibility.ts`, `resolveLabPolicy` with `lab: "pci"`, `pciSimMode`, `labScreens().coachReadouts`), the trainee's QCA on stored runs (`src/ui/lab/QcaTool.tsx`, `src/ui/lab/ReferenceMonitor.tsx`), the measurement and sizing actions and the live log (`src/simulation/pci/actions/assessment.ts`), the measurement and sizing panel (`src/ui/pci/PciAssessPanel.tsx`) and the lab wiring (`src/ui/pci/PciLab.tsx`).

No dose, threshold or device dimension is added. The sizing rules are `sizeFor` in `src/simulation/pci/lesionAssessment.ts`, unchanged; the box labels, nominal and rated burst pressures and compliance charts are the catalogue's (`boxLabel`, `chartDiameter` in `src/simulation/pci/equipment.ts`), unchanged. The QCA algorithm and its settings are `src/simulation/imaging/qca.ts` (`QCA_PARAMS`), unchanged; 1 Fr = 1/3 mm (`MM_PER_FRENCH`) as there.

| Parameter | File | Value | Unit | Rests on |
|---|---|---|---|---|
| `QCA_MIN_FRAME_RANGE` | `src/ui/lab/QcaTool.tsx` | 8 | grey levels (8-bit) | MODEL PARAMETER. A stored frame whose sampled grey levels span less than this is taken as holding no image (a blank buffer from a failed WebGL read-back, or an unexposed frame), and QCA is refused with a notice instead of a number. Chosen well below the contrast of any vessel or catheter edge the tool measures (`QCA_PARAMS.minContrast` 12) and above rounding noise of a uniform buffer (0) |
| Frame sampling for that check | `src/ui/lab/QcaTool.tsx` (`frameMeasurable`) | every 7th pixel | pixels | Implementation choice: enough samples to tell an image from a uniform buffer without scanning every pixel on each frame change |
| QCA calibration default | `src/ui/lab/QcaTool.tsx` (`QCA_DEFAULT_FRENCH`) | 6 | Fr | The tool's earlier default, unchanged. The PCI lab now passes the guide's own French size from its GuideState |
| Lesion length of a QCA result without a narrowing below the lesion threshold | `src/ui/lab/QcaTool.tsx` (`qcaMeasurement`) | the marked segment's length | mm | Rule: the trainee marked normal to normal; with no narrowing below 80 % of the reference (`QCA_PARAMS.lesionFraction`) the segment stands for the lesion |
| Words that name or grade a complication in a live log line | `src/simulation/pci/actions/assessment.ts` (`KIND_WORDS`) | dissection: dissect, NHLBI, false lumen, intramural, haematoma; perforation: perforat, Ellis, extravasat, tamponade; no-reflow: no-reflow, slow flow, TIMI; thrombus: thrombus, thrombi, embolus, emboli, embolised, distal embolisation (not 'thrombosis' in a drug warning, nor 'coil embolisation'); air: air embol; side branch: side branch occlusion, closure, compromise or loss | rule | The plan: the live log shows only what an operator could see; labels and grades go to the debrief. A narrower list than the engine's gate (`NAMES` in `src/simulation/complications/engine.ts`), which already keeps such notes off the log: this is the screen's own check for any line that reaches the log by another path, and must not hide device actions ('branch', 'ostial' and the engine's morphology words are left to the gate) |
| When a named line is shown | `src/simulation/pci/actions/assessment.ts` (`liveLog`, `lastLiveEvent`) | once the learner has recognised that kind's cause (`causeRecognised`); the learner's own 'Assessed as:' line always | rule | The gate's rule in pci-cx-recognition, unchanged |
| IVUS reference for sizing | `src/simulation/pci/actions/assessment.ts` (`sizingImaging`) | diameter of a circle of the trainee's recorded distal reference lumen area, from the latest pre-stent run assessment | mm | Geometry (d = 2 sqrt(A / pi)); the trainee's own run assessment, never the engine's IVUS summary. 'IVUS: mean EEM' is offered only when an EEM reference is passed in, which the run assessment does not record yet |
| Sizing without a measurement | `src/simulation/pci/actions/assessment.ts` (`chooseSizing`, `sizingBases`) | no size, a prompt in the log; also with an IVUS reference but no measured lesion length (the length is never assumed) | rule | The plan: displayed sizes come from the trainee's measurement and the catalogue charts, never auto-sized from the truth |
| Visual estimate input limits | `src/ui/pci/PciAssessPanel.tsx` (`VISUAL_MAX_REF_MM`, `VISUAL_MAX_LENGTH_MM`) | reference < 8, length < 100 | mm | MODEL PARAMETER: input sanity limits that catch a mistyped entry, not clinical thresholds |
| Coach read-outs | `src/ui/pci/PciLab.tsx`, `src/ui/lab/visibility.ts` | offered only with `labScreens().coachReadouts` (guided practice with overlays toggleable), switched in the attending drawer, off until switched on; the same switch governs the table strip's latest-event line | rule | The plan: coach read-outs default off and appear only with the teaching aids, inside the attending drawer |
| QCA hint | `src/ui/pci/PciLab.tsx` | the module's tip `pci-interp-qca-calibrate` (title and text, unchanged) inside the QCA steps, with the teaching aids only | rule | Teaching at the moment it applies; the tip's text and sources are the manual's (`src/content/manual/pci-manual/09-interpreting.ts`) |
