# diag-qca-measurement: model parameters

QCA in the diagnostic lab: both references and their average, the derived area stenosis, the foreshortened-frame flag, the reported view and segment, and the comparison with the model's projected stenosis in the debrief only. Files: `src/simulation/imaging/qca.ts` (formulas, report log, verdicts), `src/ui/lab/QcaTool.tsx` (the diagnostic result and 'Report this measurement'), `src/ui/lab/ReferenceMonitor.tsx` (the report host, the model side of a report), `src/mentor/debriefChecks/qca.ts` (the debrief check).

No dose or device dimension is added. The QCA algorithm and its settings (`QCA_PARAMS`, `MM_PER_FRENCH`) are unchanged. The model's projected stenosis is `projectedStenosis` in `src/render/xray/coronaryTree.ts` (diag-lesion-morphologies), and the foreshortening of a segment is `segmentForeshortening` in `src/mentor/coverage.ts`, both unchanged.

| Parameter | File | Value | Unit | Rests on |
|---|---|---|---|---|
| Reported diameter stenosis | `qca.ts` (`referenceStenosis`, `QcaResult.dsAvgPct`, `QcaReport.dsPct`) | 100 x (1 - MLD / ((proximal + distal reference) / 2)) | % | The stenosis lesson's formula (pm-interpreting-stenosis keypoints: '%DS = 100 x (1 - MLD / average of proximal and distal reference)'); its worked example (references 3.4 and 2.6 mm, MLD 0.9 mm: 70 % on the average, about 74 % proximal, 65 % distal) is a test. The PCI lab's `dsPct` and `refMm` (reference interpolated to the MLD's position) are unchanged |
| One-ended stenoses | `qca.ts` (`dsProxPct`, `dsDistPct`) | 100 x (1 - MLD / proximal reference), and the same on the distal | % | The same lesson: the one-ended reference error in a tapering vessel. Shown beside the averaged value as the learner's own numbers |
| Area stenosis | `qca.ts` (`areaStenosisPct`) | 100 x (1 - (MLD / average reference)^2) | % | Geometry, assuming a circular lumen. The lesson: area stenosis 'is calculated from mathematical assumptions about the lumen's shape'; 'the area figure assumes a circular lumen'. Labelled 'derived, circular lumen' in the panel |
| Lesion length of a report | `qca.ts` (`buildQcaReport`) | the marked segment's length | mm | Rule: the learner marks from normal segment to normal segment (the lesson and tip pci-interp-qca-calibrate: 'measure length from normal segment to normal segment') |
| `QCA_FORESHORTENED_BELOW` | `qca.ts` | 0.8 | projected / true length of the named segment | MODEL PARAMETER: the view coverage's adequacy threshold (`DEFAULT_COVERAGE.minForeshortening` in `src/mentor/coverage.ts`; qca.test.ts checks they agree), so a view the debrief calls adequate for a segment is one QCA accepts. Oxford (via the lesson): a lesion not imaged at right angles to the beam looks shorter and more severe |
| `QCA_REPORT_TOLERANCE_PCT` | `qca.ts` | 5 | percentage points | The lab request's success criterion (docs/curriculum/lab-requests/pm-interpreting.json, pm-interpreting#0: 'within 5 percentage points of the model's true value from the correct view'). Also the margin by which another adequate stored view must show the lesion worse before the reported view counts as the milder one. Allows for calibration on a catheter a few pixels wide at the stored frame's resolution |
| Worse-view tie | `qca.ts` (`worseView`) | 0.5 | percentage points | MODEL PARAMETER: views whose projected stenoses lie within half a point of each other are a tie, broken by the less foreshortened view ('the worse, least foreshortened view') |
| Views counted for the worse view | `qca.ts` (`worseView`), `ReferenceMonitor.tsx` (`qcaTruthFor`) | the case's stored cine runs at the time of each report, excluding views that foreshorten the segment | rule | The lesson: report the stenosis from the view in which it looks worst, among views with the least foreshortening |
| Second view | `debriefChecks/qca.ts` | at least 2 stored views that lay the segment out (foreshortening at or above 0.8, lesion drawn) | views | The lesson and tip diag-interp-orthogonal-worst-view: every lesion in at least two views, ideally orthogonal |
| Lesion of a report | `ReferenceMonitor.tsx` (`lesionsInSegment`, `qcaTruthFor`) | the case's lesion whose site lies in the segment the learner names (tree's SYNTAX labels, `segmentLabelAt`); the tightest in the reported view when several | rule | Implementation: the tool measures pixels only, so the learner names the segment and the model is looked up by it |
| `QCA_REPORTS_MAX` | `qca.ts` | 50 | reports | MODEL PARAMETER: a memory bound for the page's report log |
| Report binding to a run | `debriefChecks/qca.ts` | reports of the record's case made at or after the record's start (epoch ms), diagnostic lab only | rule | Implementation: the log is in memory; the debrief reads it when the case ends. A stored record replayed later carries no reports |
| Foreshortening warning on the monitor | `ReferenceMonitor.tsx`, `QcaTool.tsx` (`foreshorteningWarning`) | shown only with `labScreens().teachingAids` (guided practice with toggleable overlays); in every other mode the flag is in the debrief only | rule | The plan: no ground truth on live screens outside guided teaching aids; the foreshortening is computed from the model's tree |
| Debrief check order | `debriefChecks/qca.ts` | 210 | registry order | After the study report's check (200) |
