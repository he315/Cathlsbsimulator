# diag-pressure-recognition-drill: model parameters

The timed pressure-trace recognition drill: the item scripts and the scoring (`src/simulation/pressureDrill.ts`), played on the haemodynamic monitor by `src/ui/sections/PressureTrainer.tsx`.

Sourced values carry their location in the code and are not repeated as model parameters: the patterns, their first actions and the reveal text come from the module text of pm-engaging (src/content/manual/pci-manual/07-engaging.ts: the damping steps, Brilakis 5.6; ventricularisation, Brilakis 5.8; catheter-tip spasm 'ventricularises, then falls further a few seconds later' and the two traps of aortic stenosis and side holes, Oxford ch 6; the usual causes of real hypotension at angiography and 'if the trace stays low with the tip free in the root, check the transducer and its connections, and if the pressure is real, treat the patient', Brilakis); the hypotension threshold `DRILL_HYPOTENSION_SYS_MMHG` 90 mmHg is the module's rule of thumb for the physiologist's call-out (07-engaging.ts line 155, the same value as labTeam.ts `MP_CALLOUT_SYSTOLIC_MMHG`); the bradycardia threshold is `PATIENT_EVENT_THRESHOLDS.bradycardiaHr` (src/ui/lab/patientEvents.ts, found-lab-session-plumbing). The drill uses the engines' own models with their defaults: the tip chamber and transducer faults of transducer.ts, the hypotension causes of hypotensionCauses.ts (`gtn-pde5`, `verapamil`, `vagal`, `fasting`, with their own MP_CAUSES), the valve area of the diag-as-pulse-not-damping scenario (`DRILL_AS_AVA_CM2`, 0.7 cm², already a MODEL PARAMETER in pkg-diag-pressure-transducer.md) and the diagnostic lab's tip-spasm model (responses.ts `tipSpasmModelFor`) with the rise below.

| `MP_DRILL.settleS` | src/simulation/pressureDrill.ts | 4 | s | MODEL PARAMETER: the tip free in the root before anything; the displayed pressure then is the stem's baseline |
| `MP_DRILL.windowS` | src/simulation/pressureDrill.ts | 8 | s of trace | MODEL PARAMETER (the plan's 8 s per item): the trace the headless run measures and the learner first sees |
| `MP_DRILL.eventAtS` | src/simulation/pressureDrill.ts | 3 | s into the window | MODEL PARAMETER: the item's action (the catheter advanced from the root to engage, or withdrawn from the ostium to the root), so that the trace before it is on the screen |
| `MP_DRILL.answerLimitS` | src/simulation/pressureDrill.ts | 12 | s from the start of the trace | MODEL PARAMETER: the lab request asks for a time limit and gives no length; the 8 s window plus 4 s |
| `MP_DRILL.stepS` | src/simulation/pressureDrill.ts | 0.02 | s | MODEL PARAMETER: the drill's step between script checks (the engine sub-steps itself) |
| `MP_DRILL.sampleEveryS` | src/simulation/pressureDrill.ts | 0.25 | s | MODEL PARAMETER: how often the displayed class is sampled for the trace's events |
| `MP_DRILL.gap.coaxial` | src/simulation/pressureDrill.ts | 0.8 | open fraction of the ostium (TipInput.gap) | MODEL PARAMETER: a coaxial seat (the value transducer.ts tipFromEngagement gives a good selective seat) |
| `MP_DRILL.gap.damped` | src/simulation/pressureDrill.ts | 0.15 | open fraction | MODEL PARAMETER: a seat against the wall that damps the trace on every drill patient (checked by pressureDrill.test.ts) |

| `MP_DRILL.gap.wedged` | src/simulation/pressureDrill.ts | 0 | open fraction | MODEL PARAMETER: the end hole wedged (also the side-hole item's seat, in the left main like every seat item so the stem's action is shared) |
| `MP_DRILL.gap.spasmSeat` | src/simulation/pressureDrill.ts | 0.11 | open fraction | MODEL PARAMETER: the spasm item's seat ventricularises on engagement, then the spasm narrows it further |
| `MP_DRILL.wallContact.spasm` | src/simulation/pressureDrill.ts | 1.6 | TipInput.wallContact, model units | MODEL PARAMETER: a firm seat that provokes the model's maximal spasm (0.9 ceiling, MP_TIP_SPASM.max) |

| `MP_DRILL.spasmRiseTauS` | src/simulation/pressureDrill.ts | 1.5 | s | MODEL PARAMETER for the spasm item's own engine: the module says the trace falls 'a few seconds after engagement' (07-engaging.ts, Oxford ch 6); the diagnostic lab's default rise (MP_TIP_SPASM.riseTauS 25 s) is unchanged |
| `MP_DRILL.causeLeadS` | src/simulation/pressureDrill.ts | gtn-pde5 60, verapamil 60, vagal 30, fasting 270 | s before the window | MODEL PARAMETERS: each cause runs with the catheter seated until its effect has developed (the fasting script removes its whole deficit, MP_CAUSES.fastingDeficitMl at fastingMlS, in 260 s) |
| `MP_DRILL.lineAirMl` | src/simulation/pressureDrill.ts | 0.3 | mL | MODEL PARAMETER: air a flush leaves in the transducer for the air item; with the fault's own 0.1 mL (MP_FAULT_AIR_ML) the engine's displayed class stays aortic (displayed pulse above MP_COUPLING.displayedDampedPulseShare of the tip's), so the item uses a larger bubble that damps it on every drill patient |
| `MP_DRILL.faultLeadS` | src/simulation/pressureDrill.ts | 6 | s before the window | MODEL PARAMETER: the line faults are already on the trace when the window opens (air with the side-hole catheter in the root, then seated; off and disconnected with the catheter engaged, then withdrawn); 6 s lets the displayed class read damped from the window's first sample on every drill patient (pressureDrill.test.ts; 2 s left it aortic for up to 2.25 s on some patients) |
| `DRILL_CONTEXT` / `DRILL_CONTEXT_POOL` | src/simulation/pressureDrill.ts | nitrate, verapamil, vasovagal signs, fasted, line flushed | stem lines | MODEL PARAMETERS of the stems: each item shows one context line, its own (the three drug or vasovagal hypotension items) or one drawn per session from the pool with library.ts rng, so no context line names the answer. A drawn line is not modelled in the engine: a nitrate or verapamil line on a non-hypotension item reads as a patient whose pressure did not fall. The PDE-5 history of the nitrate item is on its reveal, not its stem (a nitrate with a recent PDE-5 inhibitor and no fall would teach the wrong thing as a distractor) |
| Stem scripts (`drillStemAction`) | src/simulation/pressureDrill.ts | 'seat' (in the root, advanced to engage the left main at 3 s) or 'withdraw' (engaged, withdrawn to the root at 3 s); end-hole or side-hole left Judkins | | MODEL PARAMETERS: every item is one of two scripts and states its catheter, so within each set every stem part and every whole stem is shared by at least two names (pressureDrill.test.ts). The side-hole item cannot be told from a free trace by the trace alone; its catheter decides the name, and its reveal says so |
| `lv` item | src/simulation/pressureDrill.ts | tip at TipInput location 'lv' (no wall contact) from 3 s | | The left ventricular trace of the old Pressure safety page (TEACHING 'lv-danger', src/data/teachingText.ts: a catheter across the valve gives an LV trace, an injection there is a ventriculogram, withdraw to the root rather than push); the reveal's LVEDP 3-12 mmHg is Oxford's normal (src/content/manual/cath-handbook/05-specific-conditions.ts). The ventricle's pressure is the engine's own |

| `MP_DRILL.perType` | src/simulation/pressureDrill.ts | 1 | items per item type in a set | MODEL PARAMETER: stratified sampling, one trace of each pattern per set |
| `DRILL_PATIENTS` | src/simulation/pressureDrill.ts | pd-4, pd-21, pd-22, pd-33, pd-49 | generatePatient seeds | MODEL PARAMETER (a choice of seeds, all in sinus rhythm with a resting systolic of about 95-110 mmHg): on each, every item reads its label and every hypotension cause takes the true systolic below 90 mmHg (pressureDrill.test.ts); patients with a higher resting pressure stay above 90 after the vasodilator causes, and the gap bands shift a little between patients |
